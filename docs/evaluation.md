# Evaluation and grading

The course final grade is based on the following items:

* 30% - final individual written exam, done on the regular exam dates. 
    * A minimum grade of 9.5 is required.
* 70% - exercise sets and final project. 
    * A single grade will be assigned to this practical component.
    * A minimum grade of 9.5 is required.
    * Done by groups of 3 students.
    * Delivery via the group's Git repository.
